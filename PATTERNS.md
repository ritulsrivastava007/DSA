# 🧩 DSA Patterns Cheat List

Learn the pattern before memorizing the solution.

| Pattern | Use When |
|---------|----------|
| Arrays | Traversal, prefix/suffix |
| HashMap | Frequency, lookup |
| Two Pointers | Sorted arrays, pairs |
| Sliding Window | Subarrays & substrings |
| Stack | Next greater, brackets |
| Queue | BFS, simulations |
| Binary Search | Sorted data / Answer search |
| Heap | Top K / smallest-largest |
| Greedy | Local optimal choice |
| DP | Optimal substructure |
| Graph | BFS / DFS / Union Find |
| Bit Manipulation | XOR, masks |
| Math & GCD | Number theory |
